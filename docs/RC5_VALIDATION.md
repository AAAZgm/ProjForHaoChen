## 实现与边界

- Windows 优先使用 Edge / Chrome 的独立应用窗口。本次运行的浏览器配置位于本次缓存目录，程序仅保留和管理自己启动的进程。

- 普通浏览器手动打开的标签页受浏览器关闭策略限制：先尝试关闭，失败时进入独立退出提示页，不再运行 Gradio 重连界面。未安装 Edge / Chrome 时保留默认浏览器兼容路径。
- 源码启动脚本正常退出不再停在 `pause`，异常退出保留错误提示。
- 保留 rc.4 性能优化，不改变编码、解码和任务管线。
