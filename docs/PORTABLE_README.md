# 轻剪：Windows 便携版使用说明

版本：1.1.0-beta.1（D 阶段试用版）

## 第一次使用

1. 解压整个压缩包，双击 `BiliVideoTool.exe`。不要直接在压缩包内运行，也不要只复制 EXE；需要保留 `_internal` 文件夹。
2. 稍等轻剪窗口打开。拖入本地视频，或粘贴 B 站链接/分享文字并点击“下载并载入”。
3. 播放到需要的位置，设置起点和终点，再点击“应用起止时间”。
4. 点击“下一步：导出成品”，选择“通用 MP4”，确认保存文件夹，点击“开始导出”。
5. 导出完成后可预览、保存副本，或点击“打开成品”“打开所在文件夹”。

无需另装 Python、FFmpeg、ffprobe 或 Git。本地素材编辑、预览、导出可离线完成；下载视频和检查更新需要联网。程序只在本机提供页面。

## 编辑

- “在播放位置分割”把原片段替换成两段，不会重复播放整片。
- 在片段列表选择一段后，上移、下移或删除。导出严格按列表顺序。
- 消音和倍速可应用于当前片段或全部片段；修改后点击应用。最近 50 步可撤销、重做。
- 在“裁剪与水印”中提取当前画面后拖出矩形，选择裁剪或水印淡化，再应用选区。
- 水印淡化通过周围像素填补，不保证无痕；建议先用“预览当前片段效果”检查最多 5 秒的结果。
- 多种裁剪尺寸以第一个设置裁剪的保留片段统一画面大小，其余等比缩放并补边。
- 高级参数表修改后需点击“应用高级参数”；重复行会重复播放。
- 每个页面的素材和编辑历史独立。刷新/关闭页面会失去未保存的编辑状态；需要下次接着编辑时，先加入批量列表并保存方案。已有成品仍保留。

## 批量、多 P 与拼接

进入“3 · 批量与拼接”：

1. 多选本地视频，再点击“加入列表”；也可把剪辑工作台里已设置好的内容通过“将当前剪辑加入列表”加入。
2. B 站视频可展开“B 站多 P 下载”，粘贴链接并点击“识别分 P”，勾选需要的分 P 后下载。下载结果按分 P 顺序加入列表；每批最多 100 项。
3. 选择列表项后可上移、下移或移除。需要编辑时点击“载入所选素材到剪辑工作台”，完成修改后回到本页点击“用当前剪辑更新所选项”。列表保存的是加入或更新时的设置。
4. “分别导出”给每个素材生成一个成品；“按顺序拼接”把整个列表合成一个成品。选择格式和保存目录，点击“开始处理列表”。

拼接以首个素材的画面尺寸为基准；该素材有裁剪时取其中第一个设置裁剪的保留片段尺寸。其他画面等比缩放并补边，统一为 30fps，有声/无声素材可以混合拼接。

格式可选 MP4、GIF，以及 **M4A、MP3、WAV 音频**。音频导出保留截取、倍速与消音，忽略画面效果；无声素材按对应长度补静音。选择“按顺序拼接”也可合成一个音频文件。

批量导出中单项失败会继续下一项；取消保留已经完成的成品。在相同设置下点击“继续未完成任务”，跳过仍然存在的已完成文件。修改格式、目录等设置后会重新导出；拼接任务从头处理。任务结束后可在“已完成成品”中下载副本，原文件已保存到指定目录。

## 保存与恢复编辑方案

在批量页展开“保存与恢复编辑方案”，填写名称并点击“保存整个列表为方案”。`.qjproj` 文件保存在上方指定的文件夹，可复制到其他电脑。

方案包含列表顺序、所有片段的截取/消音/倍速/裁剪/水印设置、导出方式和格式，以及完整原素材。大小接近原素材总量，最多 100 个素材、合计 20 GB。保存方案需要相应磁盘空间；先把剪辑工作台的修改加入或更新到列表再保存。

下次启动后选择已有 `.qjproj` 文件，点击“恢复方案并替换当前列表”。恢复成功会替换本页列表；需要保留当前方案时请先保存。恢复失败不会改变当前列表。输出目录使用当前电脑的目录，恢复后请确认；撤销历史、已导出成品和未完成任务进度不包含在方案中。

## 导出与文件位置

“通用 MP4”使用 H.264 + AAC；“较小 MP4”最长边不超过 1280 像素并提高压缩；GIF 无声音，可调帧率和缩放。所有导出都会重新编码。

默认“自动加速”会实际检查 NVIDIA 显卡编码是否可用；不可用或处理中失败时自动使用 CPU。也可选择“CPU 兼容模式”。不需要另装 CUDA 开发工具包。画面滤镜仍由 CPU 处理，显卡模式不保证总是更快，成品体积也可能不同。

rc.3 对支持的 AV1 素材还会尝试显卡解码，成功时显示“NVIDIA 显卡解码 + 编码”。当前支持未旋转的 8 位 4:2:0 AV1；其他格式继续使用软件解码。显卡或驱动不支持时自动回退，不影响继续导出。倍速时先筛选所需画面再缩放，减少不必要的处理。

导出选项中的“成品时长”是导出视频的播放长度，不是处理耗时。处理中只显示一处进度，新任务会更新状态；实际耗时在完成后显示。

rc.4 修复部分 Windows 环境中导出进程自动降档导致的缓慢问题。程序在处理时请求高性能调度，无需手动修改系统电源或显卡设置；系统不支持时仍可继续导出。

长视频会显示当前处理阶段、编码方式、已用时间和粗略剩余时间；剩余时间可能随素材和处理阶段变化。请先截取约一分钟验证效果，再导出整片；取消后可以重新尝试其他编码方式。程序不会根据一次短样例承诺整片耗时。

在“成品保存文件夹”粘贴完整目录，可填写成品名称，不用扩展名。留空自动命名；同名文件自动避重，源文件不会覆盖。导出时自动记住目录、预设、编码方式和 GIF 参数。

默认下载素材在程序旁的 `downloads`，成品在 `output`。程序目录不可写时改用 `%LOCALAPPDATA%\BiliVideoTool\files`。进入“设置与帮助”可修改下载目录、保存当前选项，或打开这些文件夹。其他已打开页面可点击“重新读取设置”。

配置位于 `%LOCALAPPDATA%\BiliVideoTool\settings.json`。配置损坏时会保留 `settings.invalid-*.json` 备份并提示恢复默认。配置只保存偏好，不保存剪辑工程。

## 启动、退出与取消

Windows 优先使用已安装的 Edge / Chrome 打开轻剪独立窗口，不使用个人浏览器配置。重复双击会返回已有轻剪窗口，保留当前编辑内容；窗口已关闭时会重新打开。端口占用会自动选择其他端口；无法自动打开时，访问启动窗口给出的本机地址。

使用完毕请点击“设置与帮助 → 退出程序”；它会取消剩余任务，等待清理，关闭轻剪独立窗口和后台程序，不关闭其他浏览器窗口。只点窗口右上角关闭不会退出后台，下次双击可重新打开页面。强制关闭启动窗口或断电可能留下缓存，下次可清理。

没有 Edge / Chrome 时使用默认浏览器。手动打开的普通标签页会尝试自动关闭；如果浏览器限制关闭，会显示“轻剪已退出”，此时手动关闭标签页即可。

下载、预览和导出可取消。等待取消完成后，可重新编辑或重试；成功、失败、取消都会清理本次处理的中间文件和半成品。

## 缓存与诊断

缓存位于 `%LOCALAPPDATA%\BiliVideoTool\cache`，包含上传副本、短预览和处理中间文件。本次运行的缓存受到保护，正常退出时清理。启动默认清理超过 7 天的历史缓存，可设置为 1–90 天，或手动点击“清理历史缓存”。下载素材和成品不会被清理。

A/B 旧版留下的程序旁 `cache` 不属于新缓存管理范围；确认旧版已退出后可自行删除旧缓存。

遇到问题，展开“设置与帮助 → 诊断信息”，生成并复制信息。日志保存在配置目录的 `logs`，单个文件约 1 MB，最多保留 3 份轮换备份。链接及常见 Cookie/令牌会隐藏；路径可能含用户名，分享前请检查。

- 无法读取视频：重新导入完整文件；不支持音频文件或损坏的视频。
- 保存目录不可写/被占用：更换目录，或关闭占用成品的播放器后重试。
- 空间不足：清理历史缓存、更换目录或腾出磁盘空间；大视频需要额外空间保存处理中间文件。
- 网站拒绝或网络超时：确认链接可在浏览器访问，稍后重试；登录受限视频暂不提供 Cookie 导入。
- 下载清晰度选项是上限，取决于网站提供的格式；无匹配格式时可改选“最高可用”。
- Windows 关闭浏览器连接时的特定 10054 清理异常已做兼容处理；如果界面提示下载或导出失败，请保留该任务的错误详情，它与单纯连接关闭提示不同。

## 更新与迁移

点击“检查正式版更新”只读取版本信息并提供发布页，不会自动安装。没有正式 Release 或网络不可用时会给出对应提示，不影响本地编辑。

升级时退出旧版，将新版解压到新文件夹再启动。同一用户的设置会保留，包括旧版下载/输出目录，因此请先确认这些目录再删除旧程序。迁移到另一台电脑时可重新选择目录；需要旧成品时另外复制成品文件。

## 可选命令与许可

维护排查可运行 `BiliVideoTool.exe --self-test 自检结果`，会离线生成样例和报告。另支持 `--no-browser`、`--port`、`--data-dir`；保存过的自定义目录优先于 `--data-dir` 的默认目录。`BILI_CONFIG_HOME` 可指定独立配置目录，用于测试或多个隔离实例。
